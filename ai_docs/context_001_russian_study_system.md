## Task summary
Build a complete, evidence-backed system to reactivate + extend Joe's Russian in ~16 days, optimized for an **oral** goal: meeting his wife Kadriya's family (St. Petersburg, secular, they drink & toast) at a dinner on **June 15**. Joe reads Cyrillic, so the system uses **Cyrillic + stress marks + audio, no romanization**.

## What was produced
- **`source/ekaterina_guide.md`** — downloaded + de-noised copy of the original shared Google Doc «Джо» by Ekaterina "Kate" Anokhina (`[email redacted]`, created 2020-09-30), found via the Google Drive connector.
- **`source/research/`** — verified research captures used to build content: `meeting_inlaws.md`, `toasts.md` (scraped via `ff web` / Bright Data), and `verified_phrases.md` (compiled, confidence-rated).
- **`content/content.json`** — canonical single source of truth, **109 items** across 8 modules, stress-marked (U+0301), with `ru_plain` for TTS. Generated by `scripts/build_content.py`.
- **`web/`** — installable PWA (vanilla JS, no build): home/dashboard with June-15 countdown, Learn flashcards (TTS auto-play, stress in red), 5-stage graduated Drill (recognise→recall→produce→listen→role-play), localStorage progress, 16-day plan view. Manifest + service worker (offline). Icons rendered from `assets/icon.svg` via `rsvg-convert`. **Aesthetic:** constructivist "supper club" — cream paper, ink, poster red, amber; Oswald + PT Serif + PT Sans (Cyrillic-native ParaType fonts).
- **`anki/`** — `russian_family_visit.txt` (109 rows, tab-separated, HTML) + README with import steps and built-in TTS template. Generated by `scripts/build_anki.py`.
- **`printable/cheatsheet.html`** — 2-page print-to-PDF table survival sheet. Generated by `scripts/build_cheatsheet.py`.
- **`schedule/16_day_plan.md`** — day-by-day plan (May 30→June 15), risk-first, weekend-heavy, 10-min fallback. Researched via the **Gemini deep-research agent** (`gemini -p`).
- **`tutor/roleplay_protocol.md`** — AI-tutor role-play scenarios + correction rubric (Claude plays тёща/тесть).
- **`RESOURCES.md`** — curated, link-verified videos/podcasts/apps.
- **`README.md`** — front door tying the six tools together.

## Key correctness decisions (verified, not free-generated)
- «На здоро́вье» is **not** a toast (reply to thanks) → use «За здоро́вье!».
- Joe is the **зять**; in-laws are **тесть/тёща**; address elders with **вы + name & patronymic**.
- "Lawyer" = **юри́ст** (адвока́т is narrower).
- 3 items flagged **★ rehearse with Kadriya** (personal/low-confidence): `Я о́чень рад быть здесь`, `Переда́йте, пожа́луйста …`, `Я из шта́та Миссу́ри`.
